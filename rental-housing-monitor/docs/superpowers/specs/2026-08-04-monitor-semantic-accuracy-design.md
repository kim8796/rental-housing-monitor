# 모니터 의미 정확도 개선 설계

## 목표

공식 임대주택 수집 결과와 Telegram 자연어 요청이 알림까지 같은 의미를 유지하게
하고, 비어 있거나 다른 내용을 긁는 모니터가 승인되지 않게 한다.

## 설계

- 임대주택 수집은 기존 행복주택·국민임대·신혼부부 매입임대 범위를 유지한다.
  LH 공공데이터의 실제 마감일을 접수 종료일로 사용하고, 공고명에 명시되지 않은
  신청 대상을 추측하지 않는다. SH 후속 발표·동호선정 글은 신규 모집에서 제외한다.
- Scrapling 제안은 현재 시험 추출 결과가 한 건 이상이어야 한다. 키워드·상태값·
  숫자 기준·변경 조건은 사용자의 조건 문장에 실제로 근거해야 하며, 그렇지 않은
  GPT 결과는 재시도한다.
- 승인 미리보기에는 실제 키워드와 비교값을 안전하게 표시한다. 일반 알림에는 검증된
  관측값 중 제목·이름 또는 매칭 필드 값을 길이 제한과 비밀값 제거 후 표시한다.
- 기존 SQLite schema, 스케줄, 다중 사용자 소유자 경계와 승인 버튼 흐름은 바꾸지
  않는다. 청년안심주택 등 신규 공급유형은 이번 범위에서 추가하지 않는다.

## 실패 처리와 검증

- 의미가 보존되지 않거나 시험 추출이 0건이면 pending action을 만들지 않는다.
- 민감값으로 판정된 관측값은 Telegram에 노출하지 않고 안전한 안내문으로 대체한다.
- 수집기, planner, preview, runner의 회귀 테스트를 추가하고 전체 테스트와 Ruff를
  커밋·배포 직전에 한 번 실행한다.
