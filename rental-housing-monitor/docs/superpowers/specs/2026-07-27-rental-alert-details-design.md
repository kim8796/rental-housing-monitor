# 임대주택 알림 상세정보 설계

## 목적

서울·경기 임대주택 모니터가 신규 공고를 감지하면 내부 규칙명과 열리지 않는 목록
URL 대신 사용자가 바로 이해하고 열 수 있는 공고 정보를 Telegram으로 보낸다.

## 선택한 접근

고정된 `python_plugin/rental_housing` adapter의 `new_item` 알림만 기존
`rental_monitor.telegram.format_announcement` 형식으로 렌더링한다. 이 adapter는
공식 LH·SH·GH collector 결과를 고정 schema와 URL 정책으로 검증하므로 제목, 기관,
지역, 유형, 대상, 공고일, 접수기간, 상세 URL을 표시할 수 있다.

일반 Scrapling 모니터에는 수집 페이지의 임의 콘텐츠를 알림에 넣지 않는다. 기존
보안 경계를 유지하면서 내부 규칙명만 한국어 사용자 문구로 바꾼다. 임대주택 필드가
손상되었거나 형식에 맞지 않으면 알림 전송을 실패시키지 않고 이 일반 형식으로
안전하게 폴백한다.

## 검토한 대안

1. 모든 모니터의 추출 필드를 그대로 표시: 편리하지만 공격자가 제어하는 페이지
   콘텐츠나 민감값이 Telegram으로 유출될 수 있어 제외한다.
2. 목록 URL만 LH 홈 주소로 교체: 빈 페이지는 피하지만 사용자가 공고를 다시 찾아야
   하므로 문제를 해결하지 못한다.
3. 공식 임대주택 adapter만 상세 렌더링: 정확한 상세 URL과 정보가 이미 검증되어
   있고 일반 모니터의 보안 경계를 유지하므로 채택한다.

## 성공 조건

- 신규 임대주택 알림에 `new_item` 문자열과 목록 URL이 없다.
- 실제 공고 제목과 상세 URL을 포함한다.
- 일반 모니터는 임의 item 콘텐츠를 계속 숨기고 규칙 종류만 한국어로 표시한다.
- 손상된 임대주택 item은 일반 안전 알림으로 폴백한다.
- 운영 DB의 기존 관찰·중복방지 상태는 변경하지 않는다.
